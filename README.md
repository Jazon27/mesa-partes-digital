# Mesa de Partes Digital

## 1. Descripción del proyecto

Este proyecto consiste en desarrollar un prototipo de Mesa de Partes Digital utilizando Python, como parte del curso de Fundamentos de Programación de la Universidad Privada del Norte (UPN).

El sistema está inspirado en el proceso de gestión documentaria de la Municipalidad Distrital de El Agustino, donde se identificaron errores de digitación y dificultades relacionadas con información incompleta durante el registro de expedientes.

El prototipo busca facilitar el registro, validación, búsqueda, ordenamiento y almacenamiento de expedientes.

## 2. Objetivo

Desarrollar un programa en Python que permita gestionar expedientes mediante algoritmos, estructuras de control, funciones, listas y archivos, aplicando los conocimientos adquiridos durante el curso.

## 3. Funcionalidades

### Implementadas en el avance inicial

- Registrar expedientes con datos del solicitante.
- Validar que el DNI contenga 8 dígitos.
- Validar que el celular contenga 9 dígitos.
- Generar un código de expediente.
- Buscar expedientes mediante su código.
- Mostrar los expedientes registrados.
- Mostrar un menú interactivo.

### Pendientes de implementación

- Validación del correo electrónico y campos obligatorios.
- Ordenamiento general de expedientes por código.
- Organización del programa en funciones reutilizables.
- Almacenamiento y recuperación de datos mediante archivos CSV.
- Pruebas completas del sistema.

## 4. Tecnologías utilizadas

- **Python:** Lenguaje de programación.
- **Visual Studio Code:** Editor de código.
- **Git:** Control de versiones.
- **GitHub:** Repositorio colaborativo.
- **Draw.io:** Diseño del diagrama de flujo.
- **CSV:** Formato propuesto para almacenar los expedientes.

## 7. Organización del trabajo

El equipo desarrolla el proyecto de manera colaborativa, utilizando GitHub para registrar los cambios realizados en el código.

Cada integrante puede contribuir mediante commits y ramas de trabajo.

## 8. Alcance del proyecto

El sistema tiene fines académicos y no reemplaza al Sistema de Gestión Documental utilizado por la Municipalidad Distrital de El Agustino.

Durante las pruebas se utilizarán datos ficticios para proteger la información personal de los ciudadanos.

## 9. Estado del proyecto

**En desarrollo.** Actualmente se cuenta con un primer avance de programación en Python y un diagrama de flujo preliminar.

Se continuará trabajando en la validación de información, modularización del código y persistencia de datos.
